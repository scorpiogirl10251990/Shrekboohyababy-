# 🧅 Shrek's Swamp - Interactive Adventure Website 🧅

A fully interactive web experience celebrating the legendary ogre and his talkative companion Donkey! This website features games, music from the Shrek films, and all the iconic catch phrases you love.

## 🎮 Features

### 1. **🎤 Swamp Karaoke**
   - Browse classic Shrek soundtrack songs
   - View iconic lyrics from the films
   - Includes: "All Star," "I'm a Believer," "Hallelujah," and more

### 2. **🧠 Ogre Quiz**
   - 5 challenging trivia questions about Shrek and friends
   - Test your knowledge of the swamp legend
   - Get instant feedback with character responses
   - Score calculation with personalized results

### 3. **🪰 Catch the Swamp Flies Game**
   - Click the fly emoji as many times as you can
   - Relaxing, fun gameplay
   - Track your fly-catching score

### 4. **🎮 Shrek Memory Match Game**
   - Classic memory card matching game
   - Match 8 pairs of Shrek characters and symbols
   - Track your matches and test your memory

### 5. **💬 Iconic Catch Phrases**
   - Over 10 legendary quotes from the films
   - Direct quotes from Shrek, Donkey, Fiona, Puss in Boots, and more
   - Celebration of the most memorable lines

### 6. **📚 Facts & Trivia**
   - Ogre Facts: Learn about Shrek's philosophy
   - Donkey Facts: Celebrate Donkey's eternal optimism
   - World Facts: Discover the magic of Far Far Away

## 🚀 How to Use

1. **Open the Website**
   - Simply open `index.html` in your web browser
   - No installation or dependencies required
   - Works on desktop and mobile devices

2. **Navigate the Swamp**
   - Scroll through all available features
   - Click on any interactive element to play games or view information
   - Try each game and challenge yourself!

3. **Take the Quiz**
   - Answer 5 Shrek trivia questions
   - Get instant feedback with character reactions
   - See your final score and receive a custom message
   - Click "Play Again" to try again

4. **Play Games**
   - **Fly Game**: Click rapidly to catch flies
   - **Memory Game**: Match pair after pair of symbols
   - Both games track your progress in real-time
